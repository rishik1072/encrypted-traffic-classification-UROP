# Local Data Storage & Privacy Policy

This directory (`data/local/`) contains purely local, privacy-preserving operational data generated by the **Encrypted Traffic Monitor** application on your machine.

---

## 🔒 Strict Privacy Guarantee

This application operates under a **Zero-Payload, Local-Only Architecture**:

1. **No Raw Packets / Zero Payload**:
   - The application inspects packet headers strictly for statistical metadata (packet lengths, inter-arrival times, directions, protocol IDs).
   - Packet application payloads are discarded immediately in volatile memory and are **never persisted to disk**.

2. **No Raw IP / MAC Persistence**:
   - IP addresses and MAC addresses are never stored in event logs or metrics.
   - Flows are tracked using ephemeral hashed flow identifiers (e.g. `flow_a1b2c3d4_...`).

3. **No External Transmission**:
   - The application does not connect to external telemetry services, cloud endpoints, or external servers.
   - All machine learning inference and dashboard visualization occur entirely on the local device (`127.0.0.1`).

---

## 📁 Directory Structure & Storage

| Path | Contents | Retention & Policy |
| :--- | :--- | :--- |
| `logs/` | Operational logs (`application.log`, `capture.log`, `prediction.log`, `health.log`) | Rotated automatically (10 MB per file, max 5 backups). Contains no payload data. |
| `events/` | Sanitized classification prediction summaries in JSONL/CSV format. | Statistical features and model prediction outputs only. |
| `metrics/` | Local throughput, CPU/memory performance, and latency telemetry. | Aggregated numerical statistics. |
| `reports/` | System diagnostic health reports. | Local environment status. |

---

## 🛡️ Forbidden Data Types

The system security module enforces compile-time and runtime invariants that prevent saving:
- Application layer payloads (HTTP headers, TLS payloads, message contents)
- Plaintext IP addresses
- Hardware MAC addresses
- Passwords, tokens, or encryption keys
- Raw `.pcap` files during live production monitoring
