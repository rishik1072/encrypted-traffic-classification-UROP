# Slide 01: Research Problem & Motivation

## The Challenge: Ubiquitous Encryption vs Network Visibility
- Over 95% of modern internet traffic is encrypted using TLS 1.3, HTTPS, and QUIC.
- Deep Packet Inspection (DPI) is computationally expensive, legally problematic, and increasingly impossible without invasive SSL interception.
- Network administrators and security teams need real-time traffic visibility without decrypting payloads.
