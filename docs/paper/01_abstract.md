## Abstract

The widespread adoption of modern encryption protocols—including TLS 1.3, QUIC, and wire-speed tunneling solutions such as WireGuard—has largely rendered traditional Deep Packet Inspection (DPI) ineffective and privacy-invasive. Consequently, machine learning (ML) models operating on statistical Layer-3/4 transport metadata have emerged as the primary alternative for traffic classification, QoS prioritization, and security monitoring. However, a significant gap exists between published academic evaluations and real-world operational realities: prior literature frequently reports near-perfect classification performance (>95% F1) by relying on synthetic packet fixtures, ignoring temporal packet inter-arrival realities, or introducing session-level data leakage across training and test splits.

In this work, we present an end-to-end, zero-payload encrypted network traffic classification framework evaluated under strict group-aware session isolation on physical multi-environment traffic (`dataset_v2`: 301 flows, 150 independent sessions across 802.11ax Wi-Fi, Gigabit Ethernet, and Cellular LTE). Operating strictly on packet sizes, timing dynamics, directionality, and burst statistics—without inspecting payloads, extracting TLS Server Name Indication (SNI), harvesting certificates, or attempting decryption—we systematically address six fundamental research questions.

Our empirical findings establish several critical insights for edge and operational deployments:
1. **In-Domain Baseline Realism (EXP-R09):** Under strict session isolation, an in-domain Random Forest ensemble achieves **0.5873 Macro-F1** (0.5833 Accuracy), while an ultra-lightweight CART Decision Tree achieves **0.5802 Macro-F1** (0.5833 Accuracy) with **0.0694 ms** median vector inference latency ($249\times$ faster than Random Forest) and a compact **9.58 KB** serialized model footprint. This disproves legacy claims of near-perfect accuracy on real traffic while highlighting the Pareto efficiency of shallow decision trees.
2. **Feature Dimensionality & Ablation (EXP-R10):** Evaluating 84 features across 7 explicit families demonstrates that directionality asymmetry carries the highest discriminative density (**0.4241 Macro-F1** using only 3 features). Furthermore, a validation-selected 3-feature subset achieves **0.6708 Test Macro-F1**, whereas utilizing all 84 features degrades performance to 0.2931 Macro-F1 due to dimensionality curse and overfitting.
3. **Physical vs. Tunnel Generalization (EXP-R11):** The statistical transport profile demonstrates robust medium-invariance across physical transmission layers, maintaining **0.9325 Macro-F1** on unseen Ethernet and Cellular LTE test environments. However, tunnel evaluation reveals an asymmetric vulnerability: models trained on direct traffic collapse to **0.3407 Macro-F1** ($\Delta\text{F1} = -0.2594$) when encountering WireGuard (Cloudflare WARP) traffic due to fixed 1280-byte MTU padding and handshake masking, whereas tunnel-trained models transfer robustly to direct traffic (**1.0000 Macro-F1**).
4. **Physical Wire Delay Dominance in Early Triage (EXP-R12):** Investigating packet observation horizons reveals that physical wire delay accounts for **99.8%** of real-time classification latency. Evaluating the first 3 packets of an encrypted flow provides actionable triage (**0.6111 Macro-F1**, 91.67% flow coverage) in **79.94 ms** (64.04 ms physical arrival delay + 16.53 ms inference), whereas waiting for retrospective full-flow termination incurs a **59.7-second** delay ($746\times$ longer) and fails (0.0000 Macro-F1) due to long-term temporal feature dilution.
5. **Calibrated Selective Classification (EXP-R13):** Implementing a four-state confidence abstention policy tuned strictly on validation data ($\tau^* = 0.70$) monotonically reduces classification error among accepted test flows from **45.83%** down to **26.92%** at **54.17% coverage** (**0.6515 Selective Macro-F1**), reaching **90.00% accuracy** at $\tau = 0.90$. The uncalibrated test Expected Calibration Error (ECE) is 0.1996 and Brier score is 0.6061.
6. **Edge Feasibility & Resource Footprint (EXP-R14 & EXP-R15):** On host hardware (12th Gen Intel Core i5-12500H, Windows 11), warm feature extraction requires 0.3856 ms P50, enabling single-vector Decision Tree throughput of **15,600 flows/sec** with 3.11 KB disk footprint and 289.60 MB working set RAM. Full live-pipeline validation achieves 81+ predictions/sec with zero payload persistence and strict localhost isolation.

We conclude with a comprehensive analysis of system limitations—including the closed-world 6-class assumption, Windows Npcap administrative requirements, class overlap in interactive messaging/web flows, and vulnerability to adversarial packet padding—and provide a fully reproducible artifact package with cryptographic provenance.
