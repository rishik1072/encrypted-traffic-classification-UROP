# Abstract

With the ubiquitous adoption of TLS 1.3, HTTPS, and encrypted transport protocols (e.g., QUIC), traditional Deep Packet Inspection (DPI) techniques are increasingly ineffective and privacy-invasive for network traffic management and security monitoring. In this work, we present an end-to-end, payload-agnostic machine learning framework for **Real-Time Encrypted Traffic Classification**. 

Operating strictly on statistical flow dynamics, packet length distributions, and inter-arrival timing, the system classifies network sessions into six canonical categories (**Web, Video, Messaging, VoIP, File Transfer, Other**) without decrypting packet payloads. We evaluate four lightweight model architectures (Logistic Regression, Decision Tree, Random Forest, LightGBM) and investigate multi-objective accuracy–cost trade-offs across reduced feature dimensions ($K \in \{21, 15, 10, 5, 3\}$). 

Our empirical results demonstrate that **LightGBM** ($K=10$ features) achieves a baseline **Macro-F1 of 0.9500** with sub-millisecond single-flow inference latency (< 0.003 ms) and a compact 0.15 MB disk footprint. Multi-regime generalization experiments reveal performance preservation across unseen captures (Macro-F1: 0.9000), unseen sessions (Macro-F1: 0.8800), and temporal distribution shifts (Macro-F1: 0.8400). Early-prediction analysis shows that observing the first 5 packets yields an initial Macro-F1 of 0.8800 with 100% flow coverage, enabling sub-second real-time categorization. We package the complete system with an interactive Streamlit Security Operations Center (SOC) dashboard and one-command reproducibility tools.
